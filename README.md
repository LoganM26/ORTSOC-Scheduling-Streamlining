# How to turn XLSX into CSV
1. Open spreadsheet and copy the list of names from each day into a new sheet.
2. When pasting use the Transpose feature to rotate the data 90 degrees.
3. Place the lists of names end to end without any headers or extra rows/columns (just the names). 
4. When you are done you should have a spreadsheet with a row for each 30 minute block and names going left to right in columns.
5. Time starts 7:00am Monday and goes to 6:00pm Friday for a total of 120 rows.

Things to check for:
Check that GRC and SECOPS both go from 7am to 7pm (sometimes they don't).
Remove blank rows/columns they get in the way.
Remove the reserved block for class to ensure "CS428" doesn't become a student.
