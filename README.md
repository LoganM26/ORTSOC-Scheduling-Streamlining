# Category Work Around
Microsoft is bugged, who's surprised. 
Here is the category work around:
After you import the .ics file, Outlook Calendar tags the events correctly but doesn't recognize the tags as their own categories
Solution: Create a dummy/test event and manually give it the category (GRC/SECOPS) using the "categorize" button
From there you can give it a color and repeat for the other category and it should now be filterable by rotation (you can delete the dummy/test events after)
